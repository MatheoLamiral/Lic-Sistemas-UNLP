# 4. Sistemas Colaborativos e Interfaces no convencionales

> Aparecen poco y de forma aislada en los parciales (suelen ser la 4ª sección, corta). Con la definición + ejemplos alcanza.

## Sistemas Colaborativos ❗ (cuando cae, es esto)
**Definición**: sistemas que permiten que varias personas **trabajen en conjunto**, con interacciones según disponibilidad **temporal** (sincrónica / asincrónica) y **espacial** (mismo lugar / distribuido).
**3 tipos / ejemplos** (pedido típico): **Wikis, Foros, Repositorios, Mail / chats**. (Ej. clásico: matriz tiempo-espacio del groupware.)

## Interfaces no convencionales (no tradicionales)
**Interfaces hápticas**: transmiten sensaciones de **tacto/fuerza**. Ejemplos válidos:
- Guante que permite "sentir" objetos virtuales.
- Joystick/volante con **force feedback** (resistencia).
- Cinturón de navegación con vibración para personas ciegas.
- Casco VR con vibración.
*(Un monitor común o una pantalla táctil simple NO son hápticas en el sentido de fuerza.)*

Otras familias mencionadas: interfaces de voz, gestuales, realidad aumentada/virtual, tangibles.
