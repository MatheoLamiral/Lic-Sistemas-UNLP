# Ayudamemoria IS3 — Índice y prioridades

Notas breves para repasar, basadas en el patrón de los parciales (2019–2025).
`❗` = muy preguntado · `❗❗` = casi seguro que cae.

## Estructura típica del parcial
4 secciones fijas: **1) Administración de Proyectos · 2) Calidad · 3) Auditoría · 4) Sistemas Colaborativos / Interfaces no convencionales**.
- 2024 → multiple-choice + desarrollo. Resto → desarrollo.
- Casi siempre hay un ítem **práctico** (clasificar un proyecto, identificar stakeholders + matriz, combinar métricas).

## Ranking de lo más tomado
1. **Stakeholders** (identificación → matriz/mapa → plan de comunicación) ❗❗
2. **Triángulo de alcance** + 5 restricciones ❗
3. **Programa vs Proyecto** + relación ❗
4. **Calidad producto/proceso** + modelos y evaluación ❗
5. **ISO 9001 a software → ISO 90003:2018** ❗❗ (respuesta fija que se repite)
6. **Tipos de opinión del auditor** (4) ❗❗
7. **Métricas en 4 niveles** (combinar + crear nueva) ❗
8. **Calidad de datos ISO 25012** (inherente vs dependiente) ❗
9. **Gobernanza vs Administración de TI / COBIT** ❗ (en aumento)
10. **COCOMO** (original 3 modelos / 2.0) + estimación de esfuerzo ❗
