## Cuadro resumen: tipos de calidad, modelos y evaluadores

| Tipo de calidad | MODELO (define QUÉ características) | EVALUACIÓN (define CÓMO se evalúa) |
| --------------- | ---------------------------------- | ---------------------------------- |
| **Producto** | ISO/IEC 9126-1 (6 car.) → **25010** (8 car.) | ISO/IEC 14598 → **25040** (5 pasos) |
| **Datos** | ISO/IEC **25012** (15 car., 2 puntos de vista) | ISO/IEC 25024 (métricas de datos) |
| **Proceso** | ISO/IEC **12207** (procesos del ciclo de vida) | ISO/IEC 15504 (SPICE) → **33000** (capacidad/madurez) |
| **Servicio** | ISO/IEC **20000** (gestión de servicios de TI) | Certificación bajo ISO/IEC 20000-1 |
| **Organización (SGC)** | ISO **9001** (+ **90003** para software) | Auditorías (ISO 19011) |

> **Cómo leerlo:** MODELO = *qué* se debe cumplir · EVALUACIÓN = *cómo* se mide/audita.
> **Flechas (→):** "reemplazada por" (la familia SQuaRE 25000 reemplazó a 9126 y 14598; la 33000 reemplazó a la 15504).
> **No mezclar:** 9126/25010 = producto · 25012 = datos · 12207 = proceso.
